# Plan: Phase 4 Plan 1 — Public & Admin REST APIs

**Phase:** 4 — Public & Admin REST APIs
**Plan:** 04-01
**Goal:** Implement all 30 public and admin REST endpoints with standard response envelopes, validation, pagination, honeypot protection, rate limiting, and dashboard stats.
**Requirements:** API-01 through API-12, ADMIN-01 through ADMIN-15

<tasks>

## Task 1: Create Request & Response DTOs (`com.globalnex.dto`)
- `dto/inquiry/InquiryCreateRequest.java`: name, email, phone, serviceLabel, message, website (honeypot), consent.
- `dto/inquiry/InquiryStatusUpdateRequest.java`: status (`NEW`, `READ`, `ARCHIVED`).
- `dto/blog/BlogPostRequest.java`: title, slug, excerpt, content, coverImage, author, tags, status, seo.
- `dto/story/SuccessStoryRequest.java`: clientName, slug, serviceSlug, summary, fullStory, image, outcome, status, featured.
- `dto/service/ServiceUpdateRequest.java`: tagline, heroImage, description, offerings, process, faqs, isFeaturedOnHome, order, seo.
- `dto/page/PageContentUpdateRequest.java`: title, blocks, seo.
- `dto/settings/SiteSettingsUpdateRequest.java`: companyName, primaryEmail, phone, address, mapEmbedUrl, socials, departmentEmails.
- `dto/stats/DashboardStatsResponse.java`: newInquiries, totalInquiries, publishedPosts, publishedStories.

## Task 2: Utility & Rate Limiting (`com.globalnex.util`, `com.globalnex.security`)
- `util/SlugUtil.java`: Generates URL-friendly slugs from strings.
- `security/InquiryRateLimiter.java`: Max 5 inquiries per hour per IP.

## Task 3: Implement Business Services (`com.globalnex.service`)
- `ServiceService.java`: find all (ordered), find featured, find by slug, update service.
- `BlogService.java`: find published paginated, find published by slug, admin find all paginated, admin create (with auto-slug), update, delete.
- `SuccessStoryService.java`: find published paginated, find by slug, admin find all paginated, admin create, update, delete.
- `InquiryService.java`: submit inquiry (honeypot check, rate limiting, IP hash), admin list paginated with status/service/keyword filters, admin find by ID, admin update status.
- `PageContentService.java`: find by slug, update page content.
- `SiteSettingsService.java`: get public settings, admin update settings.
- `DashboardStatsService.java`: compute dashboard counters.

## Task 4: Implement Public REST Controllers (`com.globalnex.controller`)
- `ServiceController.java`: `GET /services`, `GET /services/{slug}`.
- `BlogController.java`: `GET /blog`, `GET /blog/{slug}`.
- `SuccessStoryController.java`: `GET /success-stories`, `GET /success-stories/{slug}`.
- `InquiryController.java`: `POST /inquiries`.
- `PageContentController.java`: `GET /pages/{slug}`.
- `SiteSettingsController.java`: `GET /settings`.

## Task 5: Implement Admin REST Controllers (`com.globalnex.controller.admin`)
- `AdminServiceController.java`: `PUT /admin/services/{slug}`.
- `AdminBlogController.java`: `GET /admin/blog`, `POST /admin/blog`, `PUT /admin/blog/{id}`, `DELETE /admin/blog/{id}`.
- `AdminSuccessStoryController.java`: `GET /admin/success-stories`, `POST /admin/success-stories`, `PUT /admin/success-stories/{id}`, `DELETE /admin/success-stories/{id}`.
- `AdminInquiryController.java`: `GET /admin/inquiries`, `GET /admin/inquiries/{id}`, `PATCH /admin/inquiries/{id}`.
- `AdminPageController.java`: `PUT /admin/pages/{slug}`.
- `AdminSettingsController.java`: `PUT /admin/settings`.
- `AdminStatsController.java`: `GET /admin/stats`.

## Task 6: Unit & Controller Integration Tests
- Create tests for service endpoints, blog CRUD, inquiry submission with honeypot, rate limiting, and stats endpoint.

</tasks>
