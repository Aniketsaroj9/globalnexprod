<tasks>

## Task 1: API Client & Auth Context (`src/lib/api.js`, `src/context/AuthContext.jsx`)
- Configure Axios instance with `baseURL: import.meta.env.VITE_API_BASE_URL || '/api'`, `withCredentials: true`, timeout 15000ms.
- Add response interceptor to normalize `{ success, data, meta }` and standard error responses.
- Implement `AuthContext` (`user`, `isAuthenticated`, `isLoading`, `login`, `logout`, `checkAuth`). Bootstrap `/auth/me` on initial load.
- Implement `ProtectedRoute` component to redirect unauthenticated visitors to `/admin/login`.

## Task 2: Endorsement UI Component Library (`src/components/ui/`)
- `Button.jsx`: variants (`primary` [seal red stamp], `secondary` [dark ink], `outline` [rule border], `ghost`), sizes (`sm`, `md`, `lg`), loading spinner state.
- `Input.jsx`: label, helper text, error message, required indicator, aria attributes.
- `Select.jsx`: custom styled select with option groups.
- `Textarea.jsx`: multiline input with character counter and auto-resize support.
- `Card.jsx`: document-like paper background, subtle rule border, optional header/footer.
- `Badge.jsx`: status chip variants (`new` [seal], `read` [bond], `archived` [rule], `published` [veridian], `draft` [brass]).
- `Spinner.jsx`: minimal seal-ring loading indicator.
- `Pagination.jsx`: page numbers, previous/next buttons, total items indicator.
- `EmptyState.jsx`: empty ledger illustration, message, call to action.
- `ErrorState.jsx`: error banner / card with retry button.
- `Modal.jsx`: accessible backdrop dialog with focus trapping and ESC support.
- `Accordion.jsx`: animated expand/collapse for FAQ items and service menus.
- `SectionHeading.jsx`: Fraunces display typography, subtitle, optional ledger badge/stamp.
- `Breadcrumb.jsx`: navigation trail with home link and active page indicator.

## Task 3: Layout Components (`src/components/layout/`)
- `Navbar.jsx`: sticky header, GlobalNex emblem + logotype, desktop nav with Services dropdown menu, Contact button, ThemeToggle, mobile hamburger toggle + animated sliding drawer with service accordion.
- `Footer.jsx`: 4 columns (About + Certifications, Services list, Department Email Aliases, Quick Links), Social links, copyright, legal disclaimer.
- `AdminLayout.jsx`: Admin sidebar with active page indicators, breadcrumb header, logout button, and content viewport.
- `PublicLayout.jsx`: Public layout wrapper with Navbar, dynamic breadcrumbs/hero space, and Footer.

## Task 4: Routes & Page Placeholders (`src/pages/`, `src/App.jsx`)
- Create route placeholder components for all 20 routes with Helmet SEO titles and Endorsement page containers:
  - Public: `HomePage`, `AboutPage`, `ServicesPage`, `ServiceDetailPage`, `SuccessStoriesPage`, `StoryDetailPage`, `BlogPage`, `BlogPostDetailPage`, `ContactPage`, `PrivacyPolicyPage`, `TermsPage`.
  - Admin: `AdminLoginPage`, `AdminDashboardPage`, `AdminInquiriesPage`, `AdminBlogPage`, `AdminStoriesPage`, `AdminServicesPage`, `AdminSettingsPage`.
  - Catch-all: `NotFoundPage`.
- Configure `src/App.jsx` with `BrowserRouter`, `HelmetProvider`, `ThemeProvider`, `AuthProvider`, and `React.lazy` + `Suspense` with fallback spinner.

## Task 5: Verification & Quality Check
- Verify ESLint and Prettier pass (`npm run lint`, `npm run format`).
- Run `npm run build` with Vite to ensure zero bundle errors and route code-splitting works.
