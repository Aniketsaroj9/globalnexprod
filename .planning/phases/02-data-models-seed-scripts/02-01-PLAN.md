## Task 1: Create Data Models & Embedded Value Objects (`com.globalnex.model`)
- Create shared embedded objects:
  - `com.globalnex.model.SeoMetadata` (`title`, `metaDescription`, `ogImage`)
  - `com.globalnex.model.ProcessStep` (`step`, `title`, `detail`)
  - `com.globalnex.model.FaqItem` (`question`, `answer`)
  - `com.globalnex.model.ContentBlock` (`key`, `heading`, `body`)
  - `com.globalnex.model.DepartmentEmail` (`label`, `email`)
  - `com.globalnex.model.enums.PostStatus` (`DRAFT`, `PUBLISHED`)
  - `com.globalnex.model.enums.InquiryStatus` (`NEW`, `READ`, `ARCHIVED`)
  - `com.globalnex.model.enums.UserRole` (`CONTENT_ADMIN`, `SUPER_ADMIN`)
- Create 7 `@Document` entities:
  - `Service.java`: `slug` (unique, indexed), `name`, `tagline`, `icon`, `heroImage`, `description`, `offerings`, `process`, `faqs`, `isFeaturedOnHome`, `order` (indexed), `seo`, timestamps.
  - `BlogPost.java`: `slug` (unique, indexed), `title`, `excerpt`, `content`, `coverImage`, `author`, `tags`, `status`, `publishedAt`, `readTimeMin`, `seo`, timestamps.
  - `SuccessStory.java`: `slug` (unique, indexed), `clientName`, `serviceSlug`, `summary`, `fullStory`, `image`, `outcome`, `status`, `featured`, timestamps.
  - `Inquiry.java`: `name`, `email` (indexed), `phone`, `serviceRef`, `serviceLabel`, `message`, `status`, `source`, `ipHash`, `userAgent`, `notifiedAt`, timestamps. Compound index: `status: 1, createdAt: -1`.
  - `AdminUser.java`: `name`, `email` (unique, indexed), `passwordHash` (ignored on serialize), `role`, `isActive`, `lastLoginAt`, timestamps.
  - `PageContent.java`: `slug` (unique, indexed), `title`, `blocks`, `seo`, timestamps.
  - `SiteSettings.java`: singleton `id = "default"`, `companyName`, `primaryEmail`, `phone`, `address`, `mapEmbedUrl`, `socials`, `departmentEmails`, timestamps.

## Task 2: Create Lifecycle Listeners / Hooks (`com.globalnex.listener`)
- Create `BlogPostModelListener.java` extending `AbstractMongoEventListener<BlogPost>`:
  - Calculate `readTimeMin = Math.max(1, (int) Math.ceil(wordCount / 200.0))` based on `content`.
  - Auto-populate `publishedAt` with `LocalDateTime.now()` when `status == PostStatus.PUBLISHED` and `publishedAt` is null.

## Task 3: Create Spring Data MongoDB Repositories (`com.globalnex.repository`)
- Create:
  - `ServiceRepository`: `findBySlug`, `findAllByOrderByOrderAsc`, `findByIsFeaturedOnHomeTrueOrderByOrderAsc`.
  - `BlogPostRepository`: `findBySlug`, `findByStatusOrderByPublishedAtDesc` (with Pageable), `findByTagsContainingAndStatus` (with Pageable).
  - `SuccessStoryRepository`: `findBySlug`, `findByStatusOrderByCreatedAtDesc` (with Pageable), `findByServiceSlugAndStatus` (with Pageable), `findByFeaturedTrueAndStatus`.
  - `InquiryRepository`: `findByStatusOrderByCreatedAtDesc`, `findByServiceLabelOrderByCreatedAtDesc`, `findAllByOrderByCreatedAtDesc` (with Pageable).
  - `AdminUserRepository`: `findByEmail`, `existsByEmail`.
  - `PageContentRepository`: `findBySlug`.
  - `SiteSettingsRepository`: standard MongoRepository for singleton access (`findById("default")`).

## Task 4: Create Idempotent Database Seeder (`com.globalnex.seed`)
- Create `DatabaseSeeder.java` implementing `CommandLineRunner`:
  - Seed the 5 core services (`immigration`, `study-abroad`, `tours-travels`, `export-import`, `business-setup`) with rich descriptions, offerings, processes, and FAQs from PRD Section 3.4.
  - Seed default `SiteSettings` with singleton ID `"default"`, company name, official emails, address, and social links.
  - Seed default pages: `about-us`, `privacy-policy`, `terms`.
  - Seed initial Super Admin (`admin@globalnex.com` / `Admin@12345` with bcrypt 12).
  - Seed sample published blog posts and success stories for immediate visual richness.
  - Ensure all seeding is strictly idempotent (checks existence by slug/ID before inserting).

## Task 5: Unit & Model Validation Tests
- Create tests for model validation, `readTimeMin` calculation listener, and repository query methods.
