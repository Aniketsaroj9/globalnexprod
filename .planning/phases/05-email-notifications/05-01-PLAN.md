# Plan: Phase 5 Plan 1 — Email Notifications

**Phase:** 5 — Email Notifications  
**Plan:** 05-01  
**Goal:** Configure SES email sending, department routing (immigration@, education@, travel@, exports@, info@), asynchronous fire-and-forget delivery with HTML/plaintext templates, error logging, and `notifiedAt` persistence.  
**Requirements:** MAIL-01, MAIL-02, MAIL-03, MAIL-04, MAIL-05  

<context>
- Canonical reference: `SmartConnect_Complete_PRD_SpringBoot_v3.md` (Section 6.4)
- Target directory: `server/src/main/java/com/globalnex/`
</context>

<tasks>

## Task 1: Async Configuration (`com.globalnex.config.AsyncConfig`)
- Configure `@EnableAsync` with a dedicated `ThreadPoolTaskExecutor` bean `emailTaskExecutor`.
- Set pool size, queue capacity, and thread name prefix `email-executor-`.

## Task 2: Email Service & Routing (`com.globalnex.service.EmailService`)
- Implement `EmailService` using `JavaMailSender`.
- Resolve destination department email based on inquiry service (immigration -> immigration@, study-abroad -> education@, tours-travels -> travel@, export-import -> exports@, fallback -> info@ or configured SiteSettings).
- Build multi-part MimeMessage with both HTML and plain text alternatives.
- Execute `@Async("emailTaskExecutor")` `sendInquiryNotificationAsync(Inquiry inquiry)`.
- On success, set `inquiry.notifiedAt = LocalDateTime.now()` and persist update.
- On failure, catch `Exception`, log error details clearly without re-throwing to guarantee caller request is never blocked.

## Task 3: Hook Email Notification into Inquiry Submission (`InquiryService`)
- Wire `EmailService` into `InquiryService.submitInquiry`.
- Trigger async email send immediately after `inquiryRepository.save(inquiry)` for genuine (non-honeypot) submissions.

## Task 4: Unit & Integration Tests (`com.globalnex.service.EmailServiceTest`)
- Test department routing for all 5 services and unknown services.
- Test successful sending and `notifiedAt` update.
- Test exception handling (SMTP server down or network failure) ensuring no error propagates to the caller.
- Test honeypot submissions bypass email sending entirely.

</tasks>
