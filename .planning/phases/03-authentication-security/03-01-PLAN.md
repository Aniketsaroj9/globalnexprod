# Plan: Phase 3 Plan 1 — Authentication, JWT Filter, Rate Limiter & Security Configuration

**Phase:** 3 — Authentication & Security
**Plan:** 03-01
**Goal:** Implement JWT provider, cookie-based authentication filter, user details service, rate limiter, auth controller (`/api/auth/login`, `/api/auth/logout`, `/api/auth/me`), and Spring Security filter chain.
**Requirements:** AUTH-01, AUTH-02, AUTH-03, AUTH-04, AUTH-05, AUTH-06, AUTH-07, AUTH-08, SEC-01, SEC-02, SEC-04

<tasks>

## Task 1: JWT Token Provider & Security Principal (`com.globalnex.security`)
- Create `AdminUserPrincipal.java` implementing `UserDetails`:
  - Holds `AdminUser` entity, maps role to `GrantedAuthority` (`ROLE_SUPER_ADMIN` / `ROLE_CONTENT_ADMIN`).
- Create `CustomUserDetailsService.java` implementing `UserDetailsService`:
  - Queries `AdminUserRepository.findByEmail(email)`.
- Create `JwtTokenProvider.java`:
  - Loads `app.jwt.secret` (ensures min 256 bits) and `app.jwt.expiration-ms` (default 7 days = 604,800,000 ms).
  - `generateToken(Authentication authentication)` / `generateTokenFromEmail(String email)`.
  - `getEmailFromToken(String token)`.
  - `validateToken(String token)`.

## Task 2: JWT Authentication Filter & Authentication Entry Point (`com.globalnex.security`)
- Create `JwtAuthenticationEntryPoint.java` implementing `AuthenticationEntryPoint`:
  - Returns standard `ApiResponse.error(ApiError.of("UNAUTHORIZED", "Authentication required to access this resource"))` with HTTP 401.
- Create `JwtAuthenticationFilter.java` extending `OncePerRequestFilter`:
  - Reads JWT token from cookie named `token` (or `Authorization: Bearer <token>` fallback).
  - Validates token, loads user details, and sets `UsernamePasswordAuthenticationToken` in `SecurityContextHolder`.

## Task 3: IP-Based Login Rate Limiter (`com.globalnex.security`)
- Create `LoginRateLimiter.java`:
  - Tracks login attempts per IP address using a sliding time window (15 minutes).
  - Max attempts allowed: 10 per 15-minute window.
  - If exceeded, throws `ApiException("RATE_LIMITED", "Too many failed login attempts. Please try again in 15 minutes.", 429)`.

## Task 4: Authentication DTOs & Service (`com.globalnex.dto.auth`, `com.globalnex.service`)
- Create DTOs:
  - `LoginRequest.java`: `email` (valid email, not blank), `password` (not blank).
  - `UserResponse.java`: `id`, `name`, `email`, `role`, `lastLoginAt`.
- Create `AuthService.java`:
  - `login(LoginRequest request, HttpServletRequest httpRequest, HttpServletResponse httpResponse)`:
    - Checks rate limit by client IP.
    - Validates credentials using `AuthenticationManager` / `PasswordEncoder`.
    - Throws generic 401 `ApiException("UNAUTHORIZED", "Invalid email or password", 401)` on failure to prevent username enumeration.
    - On success: clears rate limit counters, updates `lastLoginAt`, issues JWT, attaches `httpOnly`, `SameSite=Strict` cookie to `HttpServletResponse`, returns `UserResponse`.
  - `logout(HttpServletResponse httpResponse)`:
    - Clears JWT cookie by setting Max-Age to 0.
  - `getCurrentUser(Authentication authentication)`:
    - Returns `UserResponse` for authenticated principal.

## Task 5: Authentication Controller (`com.globalnex.controller`)
- Create `AuthController.java` mapped to `/auth` (exposed at `/api/auth` with context path):
  - `POST /auth/login` (rate-limited, public).
  - `POST /auth/logout` (clears cookie).
  - `GET /auth/me` (requires authentication).

## Task 6: Update Spring Security Configuration (`com.globalnex.config.SecurityConfig`)
- Update `SecurityConfig.java`:
  - Register `JwtAuthenticationFilter` before `UsernamePasswordAuthenticationFilter`.
  - Set `authenticationEntryPoint(jwtAuthenticationEntryPoint)`.
  - Define `AuthenticationManager` bean using `AuthenticationConfiguration`.
  - Require authentication for `/admin/**`, `/auth/me`, and write operations.
  - Keep public endpoints accessible without authentication (`/health`, `/auth/login`, `/services/**`, `/blog/**`, `/success-stories/**`, `/pages/**`, `/settings`, `/inquiries`, `/sitemap.xml`, `/robots.txt`).

## Task 7: Unit & Integration Tests
- Create tests:
  - `JwtTokenProviderTest.java`: generates and validates tokens, checks expiration handling.
  - `LoginRateLimiterTest.java`: blocks attempts after 10 requests within window.
  - `AuthControllerTest.java`: test login with valid/invalid credentials, me, and logout.

</tasks>
