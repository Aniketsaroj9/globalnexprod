## Task 1: Initialize Maven Project & Dependencies (`server/pom.xml`)
- Create standard Maven directory hierarchy:
  - `server/src/main/java/com/globalnex/`
  - `server/src/main/resources/`
  - `server/src/test/java/com/globalnex/`
- Configure `server/pom.xml` with:
  - Parent: `spring-boot-starter-parent` 3.2.3
  - Java version: 17
  - Group: `com.globalnex`, Artifact: `smartconnect-api`, Version: `1.0.0`
  - Dependencies:
    - `spring-boot-starter-web`
    - `spring-boot-starter-data-mongodb`
    - `spring-boot-starter-security`
    - `spring-boot-starter-mail`
    - `spring-boot-starter-validation`
    - `spring-boot-starter-actuator`
    - `io.jsonwebtoken:jjwt-api:0.12.5`, `io.jsonwebtoken:jjwt-impl:0.12.5`, `io.jsonwebtoken:jjwt-jackson:0.12.5`
    - `org.projectlombok:lombok`
    - `com.googlecode.owasp-java-html-sanitizer:owasp-java-html-sanitizer:20240325.1`
    - `spring-boot-starter-test`
  - Build plugins: `spring-boot-maven-plugin` with Lombok exclusion
- Setup Maven Wrapper (`server/mvnw`, `server/mvnw.cmd`, and `server/.mvn/wrapper/maven-wrapper.properties`)

## Task 2: Core Spring Boot Application & Configuration
- Create `SmartConnectApiApplication.java` with `@SpringBootApplication` and `@EnableMongoAuditing`.
- Create `server/src/main/resources/application.yml` and `server/src/main/resources/application-dev.yml` configuring:
  - `server.port`: `${PORT:8080}`
  - `server.servlet.context-path`: `/api`
  - `spring.data.mongodb.uri`: `${MONGODB_URI:mongodb://localhost:27017/globalnex}`
  - `spring.data.mongodb.auto-index-creation`: `true`
  - `app.jwt.secret`: `${JWT_SECRET:smartconnect_default_secret_key_at_least_32_bytes_long_123456}`
  - `app.jwt.expiration-ms`: `${JWT_EXPIRATION_MS:604800000}` (7 days)
  - `app.client.origin`: `${CLIENT_ORIGIN:http://localhost:5173}`
- Create `server/.env.example` documenting all environment variables.

## Task 3: Security & CORS Configuration Skeleton
- Create `com.globalnex.config.SecurityConfig` permitting `/api/health`, `/api/auth/login`, and public GET routes, with CORS configuration allowing `CLIENT_ORIGIN` credentials and standard HTTP methods.
- Create `com.globalnex.config.MongoConfig` for Mongo auditing and custom conversions if needed.

## Task 4: Standard API Envelope & Health Endpoint
- Create standard response envelopes:
  - `com.globalnex.dto.ApiResponse<T>` (`success: boolean`, `data: T`, `meta: ResponseMeta`)
  - `com.globalnex.dto.ApiError` (`code: String`, `message: String`, `details: List<ValidationError>`)
- Create `com.globalnex.controller.HealthController` mapped to `GET /health` (exposed at `/api/health` with context-path) returning:
  ```json
  {
    "success": true,
    "data": {
      "status": "ok",
      "uptime": <milliseconds>,
      "db": "connected" | "disconnected"
    }
  }
  ```
- Add unit/integration test `SmartConnectApiApplicationTests.java` and `HealthControllerTest.java`.
