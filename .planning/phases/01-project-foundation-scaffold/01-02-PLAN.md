## Task 1: Initialize Vite React Project & Dependencies (`client/`)
- Initialize Vite + React project in `client/` with:
  - `react`, `react-dom` (^18.2.0)
  - `react-router-dom` (^6.22.0)
  - `axios` (^1.6.0)
  - `lucide-react` (^0.344.0)
  - `react-helmet-async` (^2.0.4)
  - `tailwindcss` (^3.4.1), `postcss`, `autoprefixer`
  - `prettier`, `prettier-plugin-tailwindcss`, `eslint`
- Configure `client/vite.config.js`:
  - Dev server port: 5173
  - API proxy for `/api` pointing to `http://localhost:8080`
- Create `client/.env.example` and `client/.env.development` (`VITE_API_URL=/api`).

## Task 2: Configure Endorsement Design Tokens & Typography
- Load Google Fonts in `client/index.html`:
  - `Fraunces` (weights 400, 700, 900, with `WONK` 1)
  - `Public Sans` (weights 400, 500, 600, 700)
  - `Courier Prime` (weights 400, 700)
- Configure `client/tailwind.config.js` with:
  - Palette:
    - `ink`: `#152238`
    - `ink-2`: `#33445F`
    - `ink-3`: `#6B7A92`
    - `bond`: `#EDEFE8`
    - `paper`: `#F5F6F1`
    - `field`: `#DDE2DA`
    - `rule`: `#C3C8BC`
    - `seal`: `#B0332B`
    - `brass`: `#A8843C`
    - `veridian`: `#1F5D4C`
  - Dark mode (`class` strategy):
    - `dark-bg`: `#0E1725`
    - `dark-surface`: `#141F30`
    - `dark-type`: `#E7EAE2`
    - `dark-rule`: `#2A3648`
    - `dark-field`: `#1B273A`
  - Font families:
    - `display`: `['Fraunces', 'Georgia', 'serif']`
    - `body`: `['Public Sans', 'sans-serif']`
    - `mono`: `['Courier Prime', 'monospace']`
  - Border radius: `2px` standard (`rounded-sm`: `2px`)
- Configure `client/src/index.css` with CSS variables, base styles, ruled input styles, Endorsement button styles (translate `-1px, -1px` + `3px 3px 0 #B0332B` offset on hover), and dark mode rules.

## Task 3: Setup Axios Client & Base Layout

- Create `client/src/context/ThemeContext.jsx` for light/dark mode toggling persisted in `localStorage`.
- Create foundational components:
  - `Button` (Endorsement styling)
  - `Card` / `LedgerRow` (Endorsement ledger styling)
  - `Input` (Ruled field styling)
  - `Badge` (Passport/Official stamp style)

- Setup ESLint (`.eslintrc.cjs`) and Prettier (`.prettierrc`) configs in `client/`.
